# paradee.TTS
A GUI for paradee TTS another TTS that is 10x faster on CPU compared to Kokoro with the same quality...

<img width="1043" height="892" alt="image" src="https://github.com/user-attachments/assets/08bbde33-668e-4dc6-ab35-c94aad7ec60e" />

Produce audio instantly.

Create a venv and install your requirements in there, then run python paradee_studio.py to launch it.

Requirements - pygame soundfile numpy and a few more things you find inside the bat file. 

The models are downlaoded to your machine. 8mb.

The voice quality is a beast, just like kokoro, but generating them is instantaneous. 

This one replaces balabolka completely!! On any CPU!!
